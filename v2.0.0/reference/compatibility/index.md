# Compatibility and Downloads

This documentation describes the versions below. With other versions, menus, messages and file formats can differ.

______________________________________________________________________

## Verified Versions

| Software                                                                                         | Version                                         | Where to get it                                                                                                                                                                                             |
| ------------------------------------------------------------------------------------------------ | ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Stellar software on Stellar X (Stellar Station, built-in nodes, Network Settings, SSH workspace) | 2.0                                             | Comes with Stellar X                                                                                                                                                                                        |
| NVIDIA Isaac Sim                                                                                 | 6.0, on Linux or Windows                        | [NVIDIA](https://docs.isaacsim.omniverse.nvidia.com/latest/installation/index.html)                                                                                                                         |
| Isaac Bridge                                                                                     | 1.0.0                                           | Release `v1.0.0` of [Sodero-labs/isaac_bridge](https://github.com/Sodero-labs/isaac_bridge) ([Isaac Bridge Installation](https://docs.sodero.io/v2.0.0/virtual_simulation/extension_installation/index.md)) |
| Device Bridge                                                                                    | No release yet: the `main` branch of 2026-10-20 | [Sodero-labs/device_bridge](https://github.com/Sodero-labs/device_bridge) ([Device Bridge](https://docs.sodero.io/v2.0.0/gateways/device_bridge/index.md))                                                  |
| Web browser                                                                                      | A recent version of Chrome or Edge              | —                                                                                                                                                                                                           |

After you update Isaac Bridge or the Device Bridge, check the connection again: the bridge serves its ports, and the Station's gateways log that they are connected ([Isaac Bridge Installation](https://docs.sodero.io/v2.0.0/virtual_simulation/extension_installation/#3-open-the-status-window), [Device Bridge › Check from Another Computer](https://docs.sodero.io/v2.0.0/gateways/device_bridge/#check-from-another-computer)).
