# Sodero Cloud Documentation

Build a simulated environment in **Studio**, configure robot software in **Stellar Station**, and view the simulation in **Theater**. Open the portal at [app.sodero.io](https://app.sodero.io).

## Start Here

1. Read [What Is Sodero Cloud](https://docs.sodero.io/sodero-cloud/v1.0.0/get_started/sodero_cloud/index.md) and [Key Concepts](https://docs.sodero.io/sodero-cloud/v1.0.0/get_started/key_concepts/index.md).
1. Follow the [Quick Start](https://docs.sodero.io/sodero-cloud/v1.0.0/get_started/quick_start/index.md) to create, view and stop your first World.
1. Configure a [Robot System](https://docs.sodero.io/sodero-cloud/v1.0.0/station/overview/index.md) when you are ready to connect controllers to simulated robots.

Robot Systems and Robot Worlds use credits from **Activate** to **Deactivate**, even while they are stopped ([Activate and Run](https://docs.sodero.io/sodero-cloud/v1.0.0/get_started/key_concepts/#activate-and-run)).

## Scope

This manual covers Sodero Cloud. For physical controllers and hardware setup, use the [Stellar X manual](https://docs.sodero.io/stellar-x/latest/). The two products run their own releases of Stellar Station, so menus, app versions and document formats can differ ([Compatibility](https://docs.sodero.io/sodero-cloud/v1.0.0/reference/compatibility/index.md)).

For help, use **Help › Contact support** in the portal or [contact Sodero](https://www.sodero.io/contact).
