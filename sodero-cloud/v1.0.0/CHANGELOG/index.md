# Documentation Changes

## v1.0.0

Documentation release: 27 October 2026.

This documentation release introduces the Sodero Cloud portal, World editing and viewing, Station configuration, account and project management, and optional connections.

- [Quick Start](https://docs.sodero.io/sodero-cloud/v1.0.0/get_started/quick_start/index.md): create, view, stop and deactivate a World.
- [Compatibility](https://docs.sodero.io/sodero-cloud/v1.0.0/reference/compatibility/index.md): check app availability and document formats before configuring controllers or transferring systems.
- Controller chapters describe functions available after the required apps and UIs are ready.
