# Changelog

v1.0.0

2026.10.30

## v1.0.0

#### Release

- **Get started.** What Sodero Cloud is, its key concepts, and a [Quick Start](https://docs.sodero.io/sodero-cloud/v1.0.0/get_started/quick_start/index.md) that creates, runs and stops a Robot World. Example files to connect a Robot System to it.
- **Account, workspaces and projects.** [Sign-in](https://docs.sodero.io/sodero-cloud/v1.0.0/account/sign_in/index.md), [workspaces and people](https://docs.sodero.io/sodero-cloud/v1.0.0/account/workspaces/index.md), [billing and usage](https://docs.sodero.io/sodero-cloud/v1.0.0/account/billing/index.md), [projects](https://docs.sodero.io/sodero-cloud/v1.0.0/projects/projects/index.md), [Robot Systems and Robot Worlds](https://docs.sodero.io/sodero-cloud/v1.0.0/projects/files/index.md), [activation](https://docs.sodero.io/sodero-cloud/v1.0.0/projects/activate_run/index.md), [libraries](https://docs.sodero.io/sodero-cloud/v1.0.0/projects/libraries/index.md) and [sharing](https://docs.sodero.io/sodero-cloud/v1.0.0/projects/sharing/index.md).
- **Worlds.** Build a Robot World in [Studio](https://docs.sodero.io/sodero-cloud/v1.0.0/worlds/studio/index.md), [prepare it for simulation](https://docs.sodero.io/sodero-cloud/v1.0.0/worlds/prepare_world/index.md) and watch it run in [Theater](https://docs.sodero.io/sodero-cloud/v1.0.0/worlds/theater/index.md).
- **Robot Systems.** Configure [Stellar Station](https://docs.sodero.io/sodero-cloud/v1.0.0/station/overview/index.md) in the cloud: apps and packages, the node graph, documents and settings, the connection to the World, and running nodes.
- **Operate robots.** [Strider](https://docs.sodero.io/sodero-cloud/v1.0.0/operate/strider/index.md), [Motion Studio](https://docs.sodero.io/sodero-cloud/v1.0.0/operate/motion_studio/index.md) and [Articulation](https://docs.sodero.io/sodero-cloud/v1.0.0/operate/articulation/index.md) with robots in a Robot World.
- **Connect and automate.** The [Project VPN](https://docs.sodero.io/sodero-cloud/v1.0.0/connect/project_vpn/index.md) and [AI agents](https://docs.sodero.io/sodero-cloud/v1.0.0/connect/ai_agents/index.md).
- **Reference.** [Compatibility](https://docs.sodero.io/sodero-cloud/v1.0.0/reference/compatibility/index.md) and [Limits and Defaults](https://docs.sodero.io/sodero-cloud/v1.0.0/reference/limits/index.md).
