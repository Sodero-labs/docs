# Documentation Changes

## v1.0.0 Draft

This draft introduces the Sodero Cloud portal, World editing and viewing, Station configuration, account and project management, and optional connections.

- [Quick Start](get_started/quick_start/index.md): create, view, stop and deactivate a World.
- [Compatibility](reference/compatibility/index.md): check app availability and document formats before configuring controllers or transferring systems.
- Controller chapters describe functions available after the required apps and UIs are ready.

Publication and product release dates are recorded when the release is published.
