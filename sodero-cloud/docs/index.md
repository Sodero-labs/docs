# Sodero Cloud Documentation

Build a simulated environment in **Studio**, configure robot software in **Stellar Station**, and view the simulation in **Theater**. Open the portal at [app.sodero.io](https://app.sodero.io).

## Start Here

1. Read [What Is Sodero Cloud](get_started/sodero_cloud/index.md) and [Key Concepts](get_started/key_concepts/index.md).
2. Follow the [Quick Start](get_started/quick_start/index.md) to create, view and stop your first World.
3. Configure a [Robot System](station/overview/index.md) when you are ready to connect controllers to simulated robots.

**Activate** prepares a cloud environment. **Run** starts its work. **Stop** ends the work but leaves the environment active. **Deactivate** releases it. Active environments and some rendering sessions use credits; check [Credits and Usage](account/billing/index.md) before starting.

## Scope

This manual covers Sodero Cloud. For physical controllers and hardware setup, use the [Stellar X manual](https://docs.sodero.io/stellar-x/latest/) for the software installed on your device. Cloud and device releases can expose different menus, app versions and document formats.

Buttons and menu names are shown as they appear in the product. Screenshots illustrate a task; availability, usage and limits are determined by your current account and installed apps.

For help, use **Help › Contact support** in the portal or [contact Sodero](https://www.sodero.io/contact).
